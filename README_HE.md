# Portfolio Compass v5.3 - Local-first PWA

גרסה המיועדת להתקנה אישית, ללא Cloudflare Access, ללא חשבון, ללא כרטיס אשראי וללא שרת אפליקציה.

## מה עובד ומה לא
- כספת AES-256-GCM מקומית, נעילה בסיסמה וגיבוי מוצפן.
- עיבוד תמונות OCR בדפדפן בלבד, לאחר הורדת נכסי Tesseract.js ו-WASM.
- התקנת PWA בדפדפן תומך והפעלה במצב לא מקוון לאחר התקנה מלאה וטעינת כל הנכסים.
- **לא נבדק OCR חי ב-Chromium בסביבה הנוכחית**. אין להזין צילומי חשבון אמיתיים עד בדיקת קבלה.
- אין כניסה עם Google, אין סנכרון בין מכשירים, אין מחירי שוק חיים.
- הסיסמה אינה ניתנת לשחזור. יש לשמור גיבוי מוצפן מחוץ למכשיר.

## בנייה
על מחשב עם Node.js 22 וגישה ל-npm:

```sh
npm install --ignore-scripts --no-audit --no-fund
npm test
npm run build
npm run test:ocr-live
python -m pytest -q tests
```

תיקיית `dist/` היא האתר המוכן לפריסה. `build.mjs` כולל את כל קובצי ה-OCR ואת קובצי ה-WASM ב-precache של Service Worker.
בצע בדיקת Chromium מלאה (ראו `tests/test_ocr_browser_live.py`) לפני שימוש אמיתי.

## התקנה בטלפון
PWA דורשת **כתובת HTTPS** להתקנה ראשונה באנדרואיד (או localhost בפיתוח). פתיחת `index.html` מתוך ZIP בטלפון אינה מתקינה PWA תקינה.
ניתן לארח את קובצי `dist/` באתר סטטי חינמי כגון GitHub Pages, אך **קוד האפליקציה עצמו יהיה ציבורי**. הנתונים נשמרים מוצפנים בדפדפן המקומי ולא באתר. לאחר פתיחה ראשונה, המתן להשלמת הורדת קובצי האפליקציה, התקן דרך תפריט הדפדפן, ובדוק מצב טיסה.
אין להעלות קובצי גיבוי, צילומי חשבון או נתוני אחזקות לריפו או לאחסון הציבורי.

## אבטחה ומגבלות
הצפנה מקומית אינה מונעת גישה לקוד האתר ואינה מגינה מפני אתר אירוח שנפרץ, עדכון קוד זדוני, תוסף דפדפן, תוכנה זדונית או אובדן מכשיר. אחסון דפדפן עלול להימחק. PWA אינה אפליקציה עצמאית מקומפלת, והתקנתה הראשונית דורשת HTTPS. מומלץ דפדפן מעודכן, נעילת מכשיר וגיבויים מוצפנים.
