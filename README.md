# Portfolio Compass

אפליקציית מעקב השקעות אישית - Local-first PWA.

## סטטוס

**תשתית מאגר בלבד. האפליקציה טרם הועלתה ולא פורסמה.**

קוד המקור המלא נמצא כרגע בחבילת המסירה שנוצרה בשיחת ChatGPT. אין להעלות למאגר הציבורי צילומי חשבון, קובצי גיבוי, סיסמאות או נתוני השקעות.

## ארכיטקטורה מתוכננת

- התקנה כאפליקציית PWA דרך HTTPS
- כספת מקומית מוצפנת, ללא סנכרון ענן
- OCR מקומי בדפדפן, ללא העברת תמונות לשרת
- GitHub Actions: בנייה, בדיקות JavaScript/Python, OCR אמיתי, ורק לאחר מכן פריסה ל-Pages
- GitHub Pages מארח קוד אפליקציה ציבורי בלבד; תיק ההשקעות אינו נמצא במאגר

## תנאי מעבר לפרסום

1. העלאת קובצי המקור המלאים באופן מאומת.
2. הרצת בדיקות CI אמיתיות, כולל OCR Chromium.
3. אימות קובצי PWA, מצב Offline ומניעת העלאות מידע.
4. הפעלת Pages רק לאחר שהבדיקות הושלמו.

אין להסתמך על repository זה כאפליקציה מתפקדת לפני השלמת התנאים.
